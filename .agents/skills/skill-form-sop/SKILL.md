# SOP

## Phase 1 -- 理解與設計

1. `READ` 使用者需求與目標 SKILL.md，確認 Skill 的目的、輸入、輸出與限制。
2. `READ` `rules/sop-格式規範.md`，依該檔案規範設計流程。
3. `THINK` 將工作拆成必要的 Phase、步驟與完成條件。

完成條件：已定義符合規範的 SOP 結構。

## Phase 2 -- 寫入與驗證

1. `WRITE` 在目標 SKILL.md 建立或更新唯一的 `# SOP` section。
2. `CHECK` 確認 SOP 可執行、可驗證，且符合格式規範；若不符合，返回 Phase 1 修正後重新檢查。

完成條件：目標 SKILL.md 具備可由 Agent 執行的 SOP。
