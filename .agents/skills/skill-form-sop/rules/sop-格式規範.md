# Skill Form sop

## Purpose

本 Skill 定義所有 SKILL.md 中 SOP section 的標準格式。

每個 Skill 都必須有一個 `# SOP` section。SOP 必須描述該 Skill 從接收任務到完成交付的主要流程。

## SOP 格式規範

SOP 必須符合以下規則：

1. 使用 `# SOP` 作為唯一的 SOP 主標題。
2. SOP 必須由一個或多個 `## Phase N -- <phase title>` 組成。
3. 每個 Phase 必須描述一個有明確目的的工作階段。
4. 每個步驟必須以受控動詞開頭。
5. 每個步驟必須描述具體行為，而不是抽象要求。
6. 每個 Phase 必須產生可檢查的結果。
7. SOP 必須包含完成前的驗證步驟。
8. 若某一步需要委派給 script、工具或其他 Skill，必須明確標記為 `DELEGATE`。

## 受控動詞

- `READ`：讀取檔案、規範、輸入或現況
- `THINK`：分析、判斷、拆解或設計
- `WRITE`：建立或修改內容
- `CHECK`：驗證內容是否符合規範
- `DELEGATE`：將工作交給 script、工具或其他 Skill
