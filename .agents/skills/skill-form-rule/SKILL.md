# SOP

## Phase 1 -- 理解與設計

1. `READ` 使用者需求、目標 Skill 的 `SKILL.md`，以及待修改的既有 RuleFile。
2. `READ` `rules/RuleFile-格式規範.md` 的所有 Rule，建立完成檢查清單。
3. `THINK` 確定每個 RuleFile 的單一主題與必要 Rule。

完成條件：已確定目標檔案與 Rule 清單。

## Phase 2 -- 寫入與驗證

1. `WRITE` 依已載入的檢查清單修改目標檔案與必要的引用說明。
2. `CHECK` 逐條驗證完成檢查清單；若有任一項未通過，修正後重新檢查。

完成條件：所有檢查項目均已通過。
